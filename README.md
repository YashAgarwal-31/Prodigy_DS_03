## Task 3: Bank Marketing Decision Tree Classifier

Built a decision tree classification workflow to predict whether a customer would subscribe to a product or service using demographic and behavioral attributes.

### Objective

Apply supervised machine learning to a customer-marketing problem and study how a decision tree converts feature patterns into interpretable predictions.

### Workflow

1. Loaded and examined the bank-marketing dataset.
2. Prepared categorical and numerical features for modeling.
3. Trained a decision tree classifier on customer attributes.
4. Evaluated predictions and interpreted the model's decision logic.

2. Keep the dataset file in the same directory as the notebook.
